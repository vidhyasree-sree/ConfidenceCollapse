## 7. Model Monitoring and Data Drift

Connect monitoring visualizations to actual backend calculations and stored results.

Implement or preserve:
- Reference dataset statistics.
- Incoming dataset comparison.
- Feature-level drift scores.
- Reference-versus-current distribution charts.
- Prediction class distribution changes.
- Performance monitoring when labelled ground truth becomes available.
- Monitoring history when stored records exist.
- Configurable warning thresholds.

Use suitable statistical techniques, such as the Kolmogorov–Smirnov test for appropriate numerical distributions and chi-square testing for suitable categorical distributions. Validate assumptions and sample sizes before interpreting statistical results.

Clearly distinguish:
- **Data drift:** changes in input feature distributions.
- **Prediction drift:** changes in predicted class distributions.
- **Performance degradation:** deterioration in measured model performance when actual labels are available.

Do not claim that data drift automatically proves model performance has degraded. Do not claim that performance can be measured accurately without the necessary ground-truth labels.

Display charts and comparisons only from actual reference data, incoming data, computed statistics, or persisted monitoring records.
